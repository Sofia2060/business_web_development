1. User (id, username, email, password, role...)  
2. Customer (id, user\_id, phone, address, default\_ring\_size...)  
3. Product (id, sku, name, material \['10K', '14K', '24K'\], weight\_gram, labor\_price, price, stock...)  
4. Category (id, name, description...)  
5. Collection (id, name, banner\_image...)  
6. Order (id, customer\_id, order\_status \['Pending', 'Shipping', 'Delivered', 'Cancelled'\], is\_retention\_applied, total\_amount...)  
7. OrderItem (id, order\_id, product\_id, ring\_size, engraving\_text, quantity, price...)  
8. Payment (id, order\_id, payment\_method, transaction\_id, status...)  
9. WarrantyRecord (id, customer\_id, product\_id, order\_id, warranty\_code, issue\_date, cleaning\_count, polishing\_count\_left...)  
10. AfterSalesService (id, warranty\_code, service\_type \['Cleaning', 'Polishing', 'Resizing'\], appointment\_date, status...)  
11. CustomerFeedback (id, order\_id, rating\_star, review\_text, sentiment\_label \['Positive', 'Negative'\], created\_at...)
